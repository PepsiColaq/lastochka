# Ласточка

[English / краткий README](README.md)

Локальный обход DPI для Android. Без чужих серверов и без подписки: трафик обрабатывается на телефоне.

Основано на открытом ПО: [ByeDPIAndroid](https://github.com/dovecoteescapee/ByeDPIAndroid), [ByeDPI](https://github.com/hufrea/byedpi), [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel).

## Скачать

Свежий APK — во вкладке [Releases](https://github.com/PepsiColaq/lastochka/releases).

1. Установите APK  
2. Разрешите VPN  
3. Нажмите **ВКЛ**

## Что умеет

- YouTube  
- Telegram (в т.ч. WebSocket-мост)  
- Другие популярные заблокированные сайты из списка доменов  
- Обновление списков доменов (при включённом обходе)  
- Российские банки / еда / TikTok и т.п. можно оставить вне VPN  

## Чего нет

- **Discord** — на части операторов (например Tele2) режется так, что локальный обход не помогает  
- **Google Gemini** — Google не отдаёт сервис в РФ (нужен зарубежный IP)  
- Это не VPN «сменить страну»: IP остаётся вашим  

## Обновления

В приложении можно проверить обновление с GitHub Releases и установить новый APK.
